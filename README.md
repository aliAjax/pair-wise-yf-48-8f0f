# pair-wise-yf-48 建筑设计竞赛匿名评审

源提示词摘要：主办方设置评分维度、权重和提交规则，评委在匿名状态下独立查看方案、打分、填写意见、声明利益冲突和保存草稿；系统提供提交进度、异常分处理、结果锁定与并列排名规则。

## 评分表换版与一致性规则

- 评分表按版本发布（见 `src/criteria.ts`）。v1 → v2：「场地回应」拆为「气候适应」「公共空间」两项，「环境策略」停用。
- 旧数据按迁移映射处理：未拆分的维度直接沿用原分；拆分项保留原分并标记「待复核」（评委逐项沿用原分或改分）；停用维度不迁移、不以默认分补齐；旧分保存在 `legacyValues` 留档。
- 两台设备同时提交同一份评分时，以修订号（revision）做乐观并发：只有携带最新修订号的写回成功，晚到写回进入待复核队列，由评委采纳或丢弃，不覆盖现值。
- 维度版本一变，旧提交状态、旧名次和有效评委数立即作废，按新版本重算；待复核评分（拆分单元格、晚到写回、利益冲突）不参加排名。
- 落盘失败时，迁移对应关系与待处理评分保留在内存（outbox），存储恢复后自动/手动重试；仍有待复核项或未落盘写回时不能锁定结果。
